
# 💼 Personal Portfolio

A fully responsive personal portfolio website built with **React** and **Bootstrap**. Showcasing projects, skills, and contact information in a sleek, modern design.

## 🚀 Features

- ✨ Modern and clean UI
- 📱 Fully responsive on all devices
- 🧰 Built with React and Bootstrap 5
- 🎨 Smooth scrolling and navigation
- 📁 Project showcase with descriptions and links
- 📬 Contact form with email functionality (optional)

## 🛠️ Tech Stack

- **React** – Frontend framework
- **Bootstrap 5** – CSS framework for responsive design
- **React Router** – For page navigation
- **EmailJS** *(optional)* – For contact form email handling

## 📦 Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/your-portfolio.git
```

2. Navigate into the project directory:

```bash
cd your-portfolio
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm start
```
